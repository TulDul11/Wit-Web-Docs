## INTRODUCCIÓN

### 1.1 ESTRATEGIA DE PRUEBAS

Se realizarán pruebas funcionales, de usabilidad y seguridad, cubriendo los diferentes módulos del sistema. Las pruebas serán ejecutadas en un entorno controlado utilizando criterios de aceptación definidos para cada historia de usuario.

### 1.2 ALCANCE

Las pruebas abarcan la verificación de funcionalidades clave como creación de usuarios, inicio de sesión, recuperación de contraseña, carga de material didáctico y diseño responsivo.
